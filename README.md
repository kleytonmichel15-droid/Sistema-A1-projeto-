# Sabores da Casa

Site de receitas culinárias desenvolvido inteiramente em **HTML5 puro**, como
projeto de estudo de HTML básico e avançado.

## Objetivo

Reunir receitas simples da culinária brasileira em um site organizado e fácil
de navegar, demonstrando o uso correto de tags semânticas, tabelas, formulários,
mídia local e elementos interativos nativos do HTML — sem depender de CSS ou
JavaScript para isso.

## Importante

Este projeto **NÃO utiliza CSS
Este projeto **NÃO utiliza JavaScript
Todo o resultado visual vem exclusivamente da estrutura HTML e da renderização padrão do navegador.
As imagens, o áudio e o vídeo usados são **arquivos locais**, guardados
dentro das pastas `img/`, `audio/` e `video/` — nenhum conteúdo é carregado
da internet .
